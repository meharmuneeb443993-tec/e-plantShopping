# Paradise Nursery Shopping Application

Paradise Nursery is an online shopping application designed for plant lovers to browse and purchase a variety of houseplants.

## Features
- Interactive landing page with company background and navigation
- Categorized houseplant catalog with thumbnails, details, and prices
- Dynamic Redux-managed shopping cart with badge counter
- Real-time cart calculations (quantity increase/decrease, item removal, total cost)
- Responsive layout built with React and Redux Toolkit
